# X 自动滚动长截屏 Android App (AutoScroll Screenshot for X)

## 为什么 X (Twitter) 更新后无法自动滚动截屏？
在 X Android 最新版的帖子详情页面中：
1. **底部常驻悬浮回复栏（Reply Dock）**：增加了 `Post your reply` 输入栏和操作控件，它始终悬浮在屏幕最下方（非滚动视图内）。
2. **手势冲突**：普通自动截屏软件（如系统自带的“截取更多”或普通长截图工具）模拟从屏幕最底部向上拖动，会直接命中此回复框，弹出软键盘并强行中断截图。
3. **图像匹配死锁**：传统基于像素差异的无缝拼接算法检测到底部这块回复栏区域完全没有位移，误以为屏幕没有滚动，或者在拼出来的长图中每隔一段就出现一个重复的回复栏。

## 本应用的解决方案
- **智能避让手势 (Safe Gesture Injection)**：滑动起始坐标动态定在底部回复栏上方 (`screenHeight - bottomExclusion - 30px`)，彻底杜绝误触输入法。
- **动态裁切拼接 (Exclusion Mask Stitching)**：在计算图像重叠度时，将底部回复栏和顶部标题栏设为排除遮罩（Mask），仅对有效中间滚动区域进行特征对比与无缝拼合。
- **轻量级悬浮胶囊 (Floating Controller)**：进入 X 帖子后，点击悬浮胶囊一键开始自动平滑滚动截屏。

## 如何编译与运行
1. 解压本 ZIP 压缩包。
2. 使用 **Android Studio Iguana / Jellyfish** 或更新版本打开项目目录。
3. 连接 Android 真机（Android 8.0+ / API 26+），点击 **Run** 安装。
4. 打开 App，依次允许：
   - 悬浮窗显示权限
   - 无障碍服务权限 (用于安全滑动)
   - 屏幕录制/截屏权限
5. 打开 X 客户端的任意长推文，点击屏幕侧边的【开始自动滚截】即可！
